# 下一轮迭代清单（2026-08-05）

## A. 业务正确性（最优先，可能影响生产）

### A1. 业务表 Service 接 TenantContext，按身份过滤
**场景**：agent 账号登录后，调 `/biz/order/list` 接口拿订单数据；当前 Service 没接 TenantContext 拼 merchant_id/agent_id 过滤，会返回所有商户订单。
**问题**：跨租户数据泄漏——代理商能看到别家代理的订单。
**当前覆盖**：CategoryServiceImpl 等 Service 在 `selectXxxList` 没加 `merchant_id` 过滤。
**解决方法**：
1. 在 Service 层统一加 `@TenantFilter` 注解 + AOP 切面自动拼 SQL
2. 或在 `Controller` 入口处统一调 `TenantService.assertDataScope(entity)` 强校验
3. 推荐：前者（AOP 透明），工作量 1.5 天
**优先级**：高

### A2. 提现冷静期结算联动余额
**场景**：提现申请 → 等待冷静期 → 管理员审核 → 入账。当前"冷静期"步骤只把 `frozen_amount` 标记为"可提现"，但**没联动** `available_amount += amount`、`withdraw_amount += amount`。
**问题**：会员申请提现后，前端显示"已提现 X 元"，但实际账户余额没变化，重复申请会超提。
**解决方法**：补 `SettleCommissionTask` / 提现审核回调的余额联动逻辑
**优先级**：高

### A3. release UI 完善
**场景**：平台给某商户发布小程序（miniprogram7）时，UI 流程只到"上传代码"，没有"提交审核→审核回调→发布上线"的完整流程。
**当前**：mpRelease 表有 `status` 字段但 UI 没暴露。
**解决方法**：
1. 后台 `biz/mprelease` 页加按钮：上传 / 提交审核 / 发布上线 / 回退
2. 后端 mpReleaseService 调微信"第三方平台" API（commit + release）
3. 工作量 1 天
**优先级**：中

### A4. Web 后台员工工作台
**场景**：员工账号（store_staff）能登录小程序核销，但 Web 后台没给员工入口；商家主账号开新员工只能走 sys/user 列表。
**当前**：员工权限 role=6 有绑定菜单，但没专门的 `/staff/index` 入口。
**解决方法**：
1. Web 后台新增 `/staff/index` 工作台
2. 路由 + 菜单按 `userType='3'`（员工）过滤
3. 工作量 0.8 天
**优先级**：中

### A5. 门店 logo 修复
**场景**：门店管理列表里 logo 显示不出来（OSS / 本地存储配置不一致）。
**当前**：表里有 logo 字段，存储用本地（`/profile/upload`），但配置 `spring.servlet.multipart.location` 路径有变化。
**解决方法**：统一用 MinIO 或 OSS，配置文件 `ruoyi-file-dev.yml`
**优先级**：低
