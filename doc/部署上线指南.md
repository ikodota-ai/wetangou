## 2. 服务器初始化

```bash
# 1) 创建运行用户
useradd -m -s /bin/bash dytuangou
passwd dytuangou

# 2) 安装 Java 17 + Nginx + Git
yum install -y java-17-openjdk nginx git       # CentOS
# 或 apt install -y openjdk-17-jdk nginx git   # Ubuntu

# 3) 创建目录
mkdir -p /var/dytuangou/{app,uploadPath,logs}
chown -R dytuangou:dytuangou /var/dytuangou
```

## 3. 上传后端 jar

```bash
# 本地构建（开发机）
cd /Users/mac/dev/dytuangou
mvn -pl ruoyi-admin -am package -DskipTests
# 产物：ruoyi-admin/target/ruoyi-admin.jar

# 上传到服务器
scp ruoyi-admin/target/ruoyi-admin.jar dytuangou@your-server:/var/dytuangou/app/
```

## 5. systemd 守护

```ini
# /etc/systemd/system/dytuangou.service
[Unit]
Description=洞天团购后端
After=network.target

[Service]
Type=simple
User=dytuangou
Group=dytuangou
WorkingDirectory=/var/dytuangou/app
EnvironmentFile=/etc/dytuangou/dytuangou.env
ExecStart=/usr/bin/java \
  -Xms512m -Xmx1024m \
  -Dspring.profiles.active=aliyun-oss \
  -Dfile.encoding=UTF-8 \
  -jar /var/dytuangou/app/ruoyi-admin.jar
Restart=always
RestartSec=10
StandardOutput=append:/var/dytuangou/logs/stdout.log
StandardError=append:/var/dytuangou/logs/stderr.log

[Install]
WantedBy=multi-user.target
```

## 6. Nginx 反向代理 + HTTPS

```nginx
# /etc/nginx/conf.d/api.example.com.conf
server {
    listen 80;
    server_name api.example.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.example.com;

    ssl_certificate     /etc/nginx/ssl/api.example.com.crt;
    ssl_certificate_key /etc/nginx/ssl/api.example.com.key;
    ssl_session_timeout 1d;
    ssl_session_cache shared:SSL:50m;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # CORS（小程序 + 管理端共用域名时无需跨域）
    add_header Access-Control-Allow-Origin $http_origin always;
    add_header Access-Control-Allow-Credentials true always;
    add_header Access-Control-Allow-Methods "GET, POST, PUT, DELETE, OPTIONS" always;
    add_header Access-Control-Allow-Headers "Authorization, Content-Type, X-App-Id" always;
    if ($request_method = OPTIONS) { return 204; }

    client_max_body_size 20M;

    location / {
        proxy_pass         http://127.0.0.1:8080;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header   Upgrade $http_upgrade;
        proxy_set_header   Connection "upgrade";
        proxy_read_timeout 60s;
    }
}
```

```bash
nginx -t && systemctl reload nginx
```

## 9. 小程序发布

### 9.1 修改 baseUrl

编辑 `miniprogram7/utils/config.js`：

```js
const BASE_URL = 'https://api.example.com'   // 生产 HTTPS
```

### 9.2 微信开发者工具配置

- 详情 → 项目设置：勾选"不校验合法域名"（仅预览时）
- 详情 → 项目设置 → 第三方网络配置：填 server 域名 + uploadFile 域名

**小程序后台**（mp.weixin.qq.com）开发 → 开发管理 → 服务器域名：

| 类别 | 域名 |
|---|---|
| request 合法域名 | `https://api.example.com` |
| uploadFile 合法域名 | `https://api.example.com`、`https://wetangou-prod.oss-cn-hangzhou.aliyuncs.com` |
| downloadFile 合法域名 | 同上 |
| 业务域名 | `https://admin.example.com`（如需嵌 H5） |

### 9.3 提审

- 微信开发者工具 → 右上角"上传" → 填版本号 1.0.1 + 项目备注
- mp.weixin.qq.com → 版本管理 → 提交审核
- 自营类目需提供：营业执照 + ICP 备案截图
- 审核通过后点击"发布" → 全网生效

## 13. 第三方平台代发布（高级）

如需"一个平台账号管多商户、避免每个商户人工发布"，需要：

1. **注册微信第三方平台**（mp.weixin.qq.com → 第三方平台）
2. **全网发布**（500 元审核费，每年 300 元年审）
3. **授权流程**：
   - 商户扫码授权给第三方平台
   - 平台用 `authorizer_access_token` 代调微信接口
   - `POST /wxa/commit` 提交代码
   - `POST /wxa/submitaudit` 提交审核
4. **本项目预留接口**：
   - `ApiMpReleaseController` 已有状态机（待提交/审核/发布）
   - 接入第三方平台需要补充 token 拉取 + 加密解密逻辑

**工作量预估**：3-5 天（含测试）。**当前版本不内置**，单商户自助发布已可走通。
