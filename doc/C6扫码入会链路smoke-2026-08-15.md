## §1 关键发现

### 1.1 完整链路
- 推客拿太阳码 → 微信扫码 → 新会员登录时 wx.login code 经 wxacode 解析 → 后端拿 openid
- 新会员 URL 带 `?inviteBy=<distributorMemberId>` → 后端写入 member.invite_by
- 下单时 placeOrder 检查 invite_by → 自动设 distributor_id
- prepay 触发 settleForOrder → commission 入账给该 distributor

### 1.2 新会员路径防自邀 bug
- `memberId0(openid)` 永远返 null (line 146-149 注释"保留 hook 留空")
- 70 行 `if (inviteBy.equals(memberId0(openid)))` 永不触发

- **新会员路径无防自邀** — 需后续修（用 openid hash 或自 memberId0 真实现）
