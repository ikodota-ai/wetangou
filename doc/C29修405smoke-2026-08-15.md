# C29 GlobalExceptionHandler 修 405 smoke · 2026-08-15

## 目标
修 C28 摸出的 known limitation: 错 HTTP method 返 HTTP 200 + body code=500, 应返 HTTP 405。

## 真实业务缺陷 (已修)
**根因**: `GlobalExceptionHandler.handleHttpRequestMethodNotSupported` 返 `AjaxResult.error(e.getMessage())`, 默认 HTTP 200
**影响**: 全局所有 controller 的错方法请求都返 200 + body, 标准 HTTP 语义错位
**修复** (1 文件):
```java
@ExceptionHandler(HttpRequestMethodNotSupportedException.class)
public ResponseEntity<AjaxResult> handleHttpRequestMethodNotSupported(HttpRequestMethodNotSupportedException e, HttpServletRequest request) {
    return ResponseEntity.status(405)
        .body(AjaxResult.error(HttpStatus.BAD_REQUEST, e.getMessage()));
}
```
+ 加 import `org.springframework.http.ResponseEntity`
+ 注意避开 RuoYi 自带 `com.ruoyi.common.constant.HttpStatus` 命名冲突, 用原始 405 数字
