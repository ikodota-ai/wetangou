## 三、页面流转（业务链路）
- 购买链路：首页/门店 → 商品详情 → (未登录→授权登录/获取手机号) → 提交订单(到店自取) → 支付 → 订单列表。
- 买单链路：门店 → 买单 → 选代金券 → 立即支付 → 结果。
- 预约链路：首页「预约到店」→ 在线预约 → 预约填写 → 预约成功弹窗 → 我的预约列表 → 预约详情。
- 个人中心枢纽：我的 → 订单 / 推客中心(→提现方式/提现记录/协议) / 会员资料 / 协议 / 客服。
- 授权横切：详情下单、完善资料等触发登录/手机号授权。
- 核心到店方式：到店自取 + 堂食预约。
