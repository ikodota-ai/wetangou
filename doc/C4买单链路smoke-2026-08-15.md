## §1 关键发现

### 1.1 bill mock 模式自动跳 confirm
- `ApiBillController.create` 注释明确：「支付 mock 模式：跳过店员确认环节，create 后直接置为已确认」
- 真实模式 `wx.pay.mockEnabled=false` 时仍走 status=0 → staff confirm → status=1
- **设计选择**：自助买单场景，前端 create 后直接轮询 status=1 即可触发 prepay

### 1.2 biz_settle_record 不在 bill 链路
- markPaid 只做：status=2 + voucher use
- **不写 settle_record**（grep 全栈无 insertSettleRecord 调用）
- 设计：bill 走 commission 路径（rate × amount），commission 走 settle_days 冷静期（7 天）后入账 available
- settle_record 是 admin 端手工分账用的（独立功能，不是 bill 自动产物）

### 1.3 biz_pay_bill 无 pay_time 列
- markPaid 代码里 `bill.setPayTime()` 不存在（也没 setter）
- DB schema 只 confirm_time + create_time + update_time
- C4 验 D1 改为 status=2，去掉 pay_time 断言
