# 小程序发布 · 商家自助操作手册

> **适用阶段**：未接入微信第三方平台（component_appid）
> **目标**：让商家自己完成小程序的"上传代码 → 提交审核 → 发布上线"
> **耗时**：首次 30 分钟，之后每次 5-10 分钟

---

## 1. 前置准备（一次性）

### 1.1 商家需要的东西

| 项目 | 用途 | 怎么获得 |
|---|---|---|
| 营业执照 | 注册小程序主体 | 已有 |
| 法人微信号 | 扫码验证主体 | 法人自己微信扫 |
| 邮箱（未注册过微信）| 小程序账号 | 自备 |
| 后台账号 | 下载代码包、查配置 | 由平台/代理商开通 |

### 1.2 商家去注册自己的小程序

1. 打开 https://mp.weixin.qq.com → 右上角「立即注册」
2. 选择「小程序」
3. 填写邮箱、密码、主体信息（个人/企业）
4. 邮箱激活 → 主体认证（法人扫脸或对公打款 1 分钱）
5. 注册成功后，**在小程序后台「开发管理 → 开发设置」**里能看到：
   - **AppID（小程序 ID）**：形如 `wx9e147c4e2151b123`
   - **AppSecret（小程序密钥）**：点击「生成」获取并保存
6. 把 AppID 发给平台/代理商填到我们后台的「商户管理 → 编辑」里

> ⚠️ **AppSecret 只能查看一次**，生成后必须立刻保存。如果丢了只能重置。

### 1.3 后台配置

平台/代理商登录后台 → 「商户管理」→ 找到对应商户 → 编辑：

- **小程序 AppID**：填商家拿到的 `wx9e147c4e2151b123`
- **小程序 AppSecret**：填对应的密钥（用于 wx.login、获取手机号等）
- **支付商户号**（如果接了微信支付）：见《微信支付配置手册》

保存后，**该商家的 appid 就和我们后台绑定了**，小程序启动时会自动识别到。

## 2. 平台/代理商：给商家下载代码包

### 2.1 操作步骤

1. 登录后台 → 「小程序发布」菜单（位于「团购运营 → 小程序发布」）
2. 顶部"代码包下载"区域：
   - **选择商家**：下拉选择目标商户
   - **API 地址**：
     - 真机调试阶段：`http://你电脑的局域网IP:8080`（如 `http://192.168.1.10:8080`）
     - 生产环境：`https://api.wetangou.com`（必须 HTTPS 备案域名）
   - 点击「下载代码包」按钮
3. 浏览器会下载一个 zip，命名规则：`dytuangou-mini-{商家编号}-{日期}.zip`

### 2.2 zip 里面是什么

```
dytuangou-mini-MC000001-20260806.zip
├── project.config.json          ← 已改写：appid / projectname / description
├── app.js
├── app.json
├── app.wxss
├── pages/                       ← 全部业务页面
├── components/                  ← 全部公共组件
├── assets/                      ← 图片、图标
├── utils/
│   └── config.js                ← 已改写：BASE_URL
└── README-发行说明.md            ← 给商家看的发布步骤
```

> 商家**不要手动改任何文件**——所有个性化都已经在打包时处理好了。

### 2.3 发给商家

- 把 zip 压缩包通过微信、邮箱、网盘发给商家
- 把操作步骤（下面的第 3 节）也发过去
- 平台/代理商在后台留底 zip 和 API 地址（方便以后重新打包）

---

## 3. 商家：在微信开发者工具里发布

### 3.1 第一次：导入项目

1. 下载并安装「微信开发者工具」：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 用**小程序管理员或开发者**的微信扫码登录
3. 左侧「小程序」→「+」→ 出现「导入项目」面板
4. **目录**：选解压后的代码包根目录
5. **AppID**：自动读取（应与你后台配置的一致）→ 不需要改
6. **项目名称**：随便取，比如「洞天团购-春熙路店」
7. 点击「导入」

> 第一次会编译 30 秒-1 分钟，编译完会自动打开模拟器。

### 3.2 加开发者（如果上传按钮是灰的）

- 商家管理员在 https://mp.weixin.qq.com → 用户身份 → 成员管理 → 添加成员
- 填运营人员的微信号，权限选「开发者」或「体验者」
- 运营人员微信会收到邀请，点同意

### 3.3 预览（自己手机看一眼效果）

1. 工具顶部「预览」按钮
2. 微信扫码 → 自己的手机就能看到运行效果
3. 检查：商品列表、门店、登录、我的资料是不是都对

### 3.4 上传代码

1. 工具右上角「上传」按钮
2. 弹窗填：
   - **版本号**：`1.0.0`（每次发版递增，建议语义化版本）
   - **项目备注**：`首次发布` / `修复XX` / `新增XX`
3. 点「上传」

上传成功后，在 https://mp.weixin.qq.com → 版本管理 → **开发版本**列表里能看到刚才传的版本。

### 3.5 提交审核

1. 登录 mp.weixin.qq.com → 版本管理 → 开发版本
2. 找到刚上传的版本 → 点「提交审核」
3. 填写：
   - 功能页面：默认填的首页就行
   - 测试账号：可以随便填一个手机号+密码（**审核人员会真测登录**）
   - 类目：选「生活服务」相关
4. 提交后状态变成「审核中」

> 微信审核通常 1-3 小时，节假日可能 1-2 天。

### 3.6 发布上线

1. 审核通过后，状态变成「审核通过」→ 点「发布」按钮
2. 几分钟后，**线上版本**就会生效
3. 用户扫码或搜索就能用了

## 4. 常见问题

### Q1: 上传代码时提示「不是该 AppID 的开发者」
- 你的微信号没被加为这个 AppID 的开发者
- 让小程序管理员在 mp.weixin.qq.com → 成员管理 → 添加你

### Q2: 真机调试网络请求失败
- 微信开发者工具右上角「详情」→「本地设置」→ **不校验合法域名 / web-view 业务域名 / TLS 版本** 全部打勾
- 手机和电脑必须在同一个 WiFi（不能手机开热点给电脑）
- 把电脑的局域网 IP（`ifconfig en0 | grep 'inet '`）告诉后台运营，让他们重打包

### Q3: 审核被拒
- 微信会发站内信告知原因，最常见：
  - **类目不对**：类目改成「生活服务 / 工具 / 商业服务」等
  - **功能未完善**：某个页面点不开、登录不了、加载白屏
  - **缺少资质**：餐饮类要食品经营许可证、医疗类要医疗机构执业许可证
- 修复后重新上传代码 → 重新提交审核

### Q4: 改了后端地址，怎么重新打包？
- 平台/代理商在后台「小程序发布 → 代码包下载」选同样商家、改 API 地址、重新下载
- zip 里 `utils/config.js` 的 BASE_URL 会自动更新
- 把新 zip 发给商家，按 3.4-3.6 走一遍即可

### Q5: 用户扫码后看到的是旧版本
- 微信有缓存，用户第一次扫码是新版，但第二次扫码可能还是旧
- 让用户**删除小程序重新搜索**或**等 5-10 分钟**（微信 CDN 缓存）

### Q6: 后台管理员怎么知道商家有没有发布？
- 暂时只能让商家主动反馈
- 未来接入微信第三方平台后，后台「小程序发布」菜单会自动显示"已发布 v1.0.3 (2026-08-06 18:30)"

---

## 5. 升级流程（第二次及以后）

平台/代理商每次发布新版本：

1. 改完代码 → 编译
2. 后台「小程序发布 → 代码包下载」→ 选商家 → 下载新 zip
3. 发给商家
4. 商家按 3.4 上传 → 3.5 审核 → 3.6 发布

> **版本号建议**：主版本.次版本.补丁号（如 1.2.3），每次强制递增，方便回滚。

## 6. 什么时候考虑接入第三方平台？

| 商家数量 | 建议 |
|---|---|
| 1-3 个 | 继续传统流程，本手册够用 |
| 5-10 个 | 强烈建议申请第三方平台（年费 300 + 1-3 天审核）|
| 10+ 个 | 必须第三方平台，否则运维成本扛不住 |

接入第三方平台后，本手册**整体废弃**，替换为《第三方平台接入操作手册》（待写）。
