### 2.3 关键模块内部逻辑（深度走查）

#### ✅ AgentServiceImpl（优秀）
- `insertAgent` 强制 `checkPlatformOnly()`，仅平台可开代理商
- `updateAgent` 代理商账号仅能改联系方式，**强制清空** 额度/到期/状态
- `checkAgentDataScope(agentId)` 防越权访问他人代理商数据

#### ✅ MerchantServiceImpl（优秀）
- `checkAppidUnique` 唯一性校验（防重复占用）
- `checkAgentQuota` 代理商额度校验
- `insertMerchant` 后 `agentMapper.increaseUsedQuota` 自动扣额度
- 修改时 `checkMerchantDataScope` 防越权

#### ✅ MerchantFeeServiceImpl（优秀）
- 状态机 `STATUS_UNPAID → STATUS_PAID / STATUS_CANCELED`
- 重复确认被拦截
- 平台开单自动补 `agentId`（按当前商户）

#### ⚠️ MpReleaseServiceImpl（注意）
- 状态机完整（5 审核 + 3 发布），但 `buildAuditItems` 用占位 `pages/index/index` —— **生产前需按实际首页路径修改**
- 真实调 `wxOpenService.submitAudit / release / rollback`

#### ⚠️ WxPayService（中等问题）
- ✅ `resolveCredential(merchantId)` 按商户取 `payMchId/payAppid/payCertSerial/payKeyPath/payApiV3Key/payNotifyUrl`
- ✅ 回调时通过 `out_trade_no → merchant_id` 路由
- ⚠️ **`isMock()` 是全局判断**（`wxPayConfig.isMockEnabled()`），不是按商户
  - 单商户场景下 OK
  - 多商户场景：A 商户配齐凭证、B 商户没配，B 仍走 mock（**合理**）；但生产环境 `isMockEnabled` 默认 `true`，需手动设 `wx.pay.mock.enabled=false`

#### ⚠️ SettlementService（注意）
- `approveWithdraw`：通过 → `withdrawAmount += amount`
- `rejectWithdraw`：驳回 → `availableAmount += amount`（退回）
- ⚠️ **`SettleCommissionTask`（Quartz）**：`commission.status 0→1` 已实现，但 **未联动推客**：
  - `frozenAmount -= amount`（释放冻结）
  - `availableAmount += amount`（计入可提现）
  - **结果**：commission.status 变了，但推客的「冻结」「可提现」永远不变 → 推客中心看到的「可提现」小于「累计佣金 - 已提现」。

### 3.2 核心业务流程端到端验证

#### 流程 1：登录 → 选门店 → 下单 → 支付 → 核销

```
1. pages/login/login
   wx.login → code → POST /api/auth/login {code, appid}
   → 后端：code2Session + resolveMerchantId + upsert Member
   → 返 token 写 wx.setStorageSync

2. pages/home/index
   pickNearestStore → 选 store
   bannerList → 显示 banner
   productList → 显示商品

3. pages/goods/detail
   productDetail → 拉商品详情
   → 点「立即购买」

4. pages/order/submit
   productDetail（再次校验价/库存）
   → POST /api/order {productId, num, memberVoucherId, distributorId}
   → ApiOrderService.placeOrder：扣库存 + 写 commission（status=0）+ 推客 frozenAmount +=

5. pages/pay/index（复用）
   → POST /api/order/prepay/{id} → 调 wxPayService.createJsapiOrder
   → 真实：返回小程序 wx.requestPayment 参数
   → 回调：ApiPayNotifyController 解密 → ApiOrderService.paySuccess
   → commission.status=0 仍冻结、推客 frozenAmount 不变（已加）

6. 到店核销
   店员 → ApiOrderController.verify {verifyCode, storeId}
   → @StoreStaffRequired 校验店员身份
   → ApiOrderService.verify：校验 storeId 归属、订单 status=1、有效期
   → status=2（已核销）
```

**评估**：下单→支付→核销闭环完整，佣金冻结自动触发。✅

#### 流程 2：推客中心 + 提现 + 冷静期结算

```
1. pages/promoter/index
   promoterInfo → /api/distributor/center
   → 拉推客档案 + 5 个金额字段（totalCommission / availableAmount / withdrawAmount / withdrawingAmount / frozenAmount）
   commissionList → /api/distributor/commission/list
   promoterFans → /api/distributor/fans

2. pages/promoter/withdraw
   → POST /api/distributor/withdraw {amount, withdrawType, account, accountName}
   → ApiDistributorController.withdraw
   → availableAmount -= amount，withdraw.status=0（待审）

3. 后台审核
   WithdrawController.audit status=1
   → SettlementService.approveWithdraw
   → withdrawAmount += amount

4. 冷静期 Quartz（每天 03:00）
   SettleCommissionTask.ryNoParams()
   → commissionService.settleExpiredCommissions(7)
   → UPDATE biz_commission SET status=1 WHERE status=0 AND create_time + 7 day <= NOW
   ⚠️ TODO：未联动 frozenAmount -= amount、availableAmount += amount
```

**评估**：提现流完整，冷静期结算有逻辑但**未联动余额**。⚠️

#### 流程 3：预约 → 确认 → 完成

2. 后台 BookingController.audit

## 5. 多租户隔离三层防护

### 5.1 拦截器链

```
请求进入
  ↓
JwtAuthenticationTokenFilter（后台）或 MemberAuthInterceptor（小程序）
  ↓
TenantContextHolder.set(...) —— 写入 ThreadLocal
  ↓
MyBatis SQL 执行
  ↓
TenantSqlInterceptor.prepare
  ├─ TenantIgnoreResolver.isIgnored(@IgnoreTenant) — 跳过
  ├─ TenantTableRegistry.isTenantTable — 仅过滤 biz_* 租户表
  └─ TenantSqlRewriter.rewrite
        ├─ 平台账号：不改写
        ├─ 代理商账号：append WHERE merchant_id IN (名下商户)
        └─ 商户账号：append WHERE merchant_id = ?
                          共享表：append WHERE merchant_id IN (0, ?)
  ↓
TenantInsertInterceptor.update
  ├─ 商户账号：强制覆盖 merchantId
  ├─ 代理商账号：未传则抛异常 / 传了必须 in (名下商户)
  └─ 平台账号：不干预
  ↓
finally: TenantContextHolder.remove()
```

## 8. 关键优点

- **MyBatis 拦截器自动追加 merchant_id**——避免 157 个 Mapper XML 手改，**业界罕见的好实践**
- **三级租户隔离**：组织权限（sys_dept）+ 业务隔离（merchant_id）+ 上下文（ThreadLocal）
- **状态机 + 留痕** 在小程序代发布、提现审核、预约取消三处均完整
- **幂等 SQL 脚本**：18 个 .sql 文件全部 NOT EXISTS / WHERE NOT EXISTS 条件插入
- **BizSelect 组件**：8 类下拉统一封装，pageSize=100 避免截断
- **`@Sensitive` 注解** 5 domain 覆盖，Jackson 3 + 注解式脱敏
- **wxOpenService 真实接入**：stateful 状态机、callWxOpen 回调封装、状态码翻译
