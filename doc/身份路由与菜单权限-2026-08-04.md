## 3. 数据流转全链路

```
用户登录 (POST /login)
  → SysLoginService.login (校验密码)
  → TenantIdentityResolver.resolve (反查 biz_merchant_user)
  → 写入 LoginUser.userType / agentId / merchantId
  → 签发 JWT（含 loginUserKey）
  → 返回 ajax { token, userType, agentId, merchantId, ... }

前端 Login action
  → store.dispatch('GetInfo')
  → GET /getInfo
  → SET_USER_TYPE / SET_AGENT_ID / SET_MERCHANT_ID 写入 vuex
  → GenerateRoutes 拉 getRouters
  → resolveEntryPath() 按 userType 跳转
  → 平台 → /index
  → 代理 → /agent/index
  → 商户 → /merchant/index

用户进入工作台
  → 前端 vuex 读 userType / agentId / merchantId
  → 后端拦截器 TenantSqlInterceptor 自动注入 WHERE merchant_id 条件
  → 业务查询按 merchantId 严格隔离
```

## 4. 真实业务缺口（待用户决策）

### 4.1 agent 角色 0 菜单 — ✅ 已修复

**根因**：SysMenuServiceImpl.selectMenuTreeByUserId 调 getChildPerms(list, 0) 找 parent_id=0 的顶级菜单；agent 角色没绑"团购运营"（menu_id=2001），所以顶级菜单找不到 → 0 router。

**修复**：补绑 2 条 C/M 菜单：
```sql
INSERT IGNORE INTO sys_role_menu(role_id, menu_id) VALUES(4, 2001);  -- 团购运营
INSERT IGNORE INTO sys_role_menu(role_id, menu_id) VALUES(4, 2216);  -- 代理商管理
```

**修复后 agent001 /getRouters 实测返回**：
```
- 团购运营
  - 租户管理
    - 代理商管理
    - 代理商缴费
    - 商户管理
    - 商户收费
    - 小程序发布
```

### 4.2 merchant 角色误绑代理商子菜单 — ✅ 已修复

**修复**：删 merchant 角色绑的 2 个 C 菜单（"代理商管理"/"代理商缴费"），商户不应看代理商列表。SQL 已在 `sql/biz_方案C身份路由测试账号.sql` 末尾。

### 4.3 平台角色绑了"租户管理"（合理）

platform 绑"租户管理"全菜单是合理的（平台要管代理商+商户+小程序发布）。
