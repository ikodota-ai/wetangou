# C11 商家端商品创建端到端 + 2 业务缺陷修复 · 2026-08-15

## 背景

8-14 计划里把「P1 商家端商品创建：10 page 无 typeCode/createProduct 入口」列为最大缺口。
本轮核查发现**前端 `pages/merchant/product/create` 已实装**（`miniprogram7/.../merchant/product/create/index.js`），
但写 C11 端到端 smoke 时**暴露出 3 个真实业务缺陷**。

## 本轮修的 3 个 P1 缺陷

### 缺陷 1：`/api/merchant/staff/me` 在多门店员工上报错 500
- **症状**：`Expected one result (or null) to be returned by selectOne(), but found: 3`
- **根因**：`MerchantStaffMapper.selectByUserId` 无 `LIMIT 1`，staff001 关联 3 个门店（100/101/200）→ 返 3 条
- **修复**：mapper 加 `order by ms.id asc limit 1`（取最早关联的作为主店）

### 缺陷 2：`/biz/productType/appCreatable` 需 admin token 才能拿 typeCode
- **症状**：mini 端调此端点返 401
- **根因**：端点未标 `@Anonymous`，需 `biz:productType:query` 权限
- **修复**：`BizProductTypeController.appCreatable` 加 `@Anonymous`（字典类公开数据）

### 缺陷 3（设计性）：`category/list?storeId=100` 拿不到平台级分类
- **现状**：`biz_product_category` 9 条数据 store_id 全是 NULL（平台级），`storeId=100` 过滤后返 `[]`
- **设计**：mini 端拿「平台级分类」应**不传** storeId；`storeId=N` 仅拿门店专属
- **smoke 修正**：C 测试用例改为不带 storeId
