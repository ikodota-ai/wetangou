# A1 业务表租户过滤验证报告（2026-08-05）

## 结论：A1 实际已实现

经过端到端验证，业务表租户过滤机制**早已通过 MyBatis 拦截器实现**，所有业务 SQL 自动追加 `merchant_id` / `IN (代理商名下商户)` 条件，**无需 Service 或 Mapper 任何改动**。

## 现有体系组件

| 组件 | 位置 | 职责 |
|------|------|------|
| `TenantContext` | `ruoyi-common/.../model/TenantContext.java` | 描述当前请求归属（平台/代理/商户）|
| `TenantContextHolder` | `ruoyi-common/.../utils/TenantContextHolder.java` | 线程级上下文，按需返回是否需过滤 |
| `TenantServiceImpl.buildContextByUserId` | `ruoyi-system/.../biz/service/impl/TenantServiceImpl.java:40` | 登录时构造上下文（含 agentId + merchantIds 列表）|
| `JwtAuthenticationTokenFilter` | `ruoyi-framework/.../security/filter/JwtAuthenticationTokenFilter.java:48` | 把 LoginUser.tenantContext 写入 ThreadLocal |
| `TenantSqlInterceptor` | `ruoyi-framework/.../tenant/TenantSqlInterceptor.java` | MyBatis 拦截器，自动改写 SQL |
| `TenantSqlRewriter` | `ruoyi-framework/.../tenant/TenantSqlRewriter.java` | JSqlParser 解析 SQL + 追加条件 |
| `TenantTableRegistry` | `ruoyi-framework/.../tenant/TenantTableRegistry.java` | 业务表注册（强隔离 19 张 + 共享 4 张）|
| `TenantInsertInterceptor` | `ruoyi-framework/.../tenant/TenantInsertInterceptor.java` | INSERT 时自动填 merchant_id |
| `TenantIgnoreResolver` | `ruoyi-framework/.../tenant/TenantIgnoreResolver.java` | 标记"忽略过滤"的方法（白名单）|

## 已注册租户表

**强隔离表（19 张）**：
biz_store, biz_store_album, biz_store_user, biz_member, biz_product, biz_product_store, biz_order, biz_booking, biz_booking_member, biz_pay_bill, biz_member_voucher, biz_distributor, biz_commission, biz_withdraw, biz_settle_account, biz_settle_record, biz_mp_auth, biz_mp_release, biz_merchant_fee

**共享表（4 张）**：biz_category, biz_voucher, biz_agreement, biz_commission_rule
> 共享表条件为 `merchant_id IN (0, ?)`，0 表示全平台通用数据

### 后端日志确认 SQL 改写

```
[租户过滤] com.ruoyi.biz.mapper.MemberMapper.selectMemberByOpenid 改写后SQL:
SELECT ... FROM biz_member WHERE (openid = ? AND merchant_id = ?) AND biz_member.merchant_id = 1

[租户过滤] com.ruoyi.biz.mapper.DistributorMapper.selectDistributorList 改写后SQL:
SELECT ... FROM biz_distributor d LEFT JOIN ... WHERE (d.member_id = ?) AND d.merchant_id = 1
```
