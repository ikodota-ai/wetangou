# C15 门店链路 smoke + 1 P0 mapper bug 修复 · 2026-08-15

## 背景

C15 摸底发现 /api/store/*（5 个端点：list/nearest/detail/services/album）之前完全没端到端 smoke 覆盖。
本轮首次写 smoke 时暴露 1 个真实 P0 mapper bug。

## 本轮修的 1 个 P0 缺陷

### 缺陷：StoreMapper.xml selectStoreList 不过滤 del_flag
- 症状：GET /api/store/list 返 del_flag=1（软删除）的门店
- 根因：
  - ApiStoreController.list 主动设了 query.setStatus(0) + query.setDelFlag(0)
  - 但 StoreMapper.xml 的 selectStoreList 根本没有 del_flag / status 的 if test 条件
  - controller 的 setDelFlag/setStatus 完全被 mapper 忽略
  - 所有小程序 /api/store/list 用户都能看到已软删除的门店
- 修复：StoreMapper.xml 加 status + del_flag 两个 if test 条件
- 影响：所有 /api/store/list 调用现在正确排除已软删除门店
