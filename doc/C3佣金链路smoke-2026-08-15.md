## §1 修复的 2 个 Bug

### 1.1 placeOrder 未 set distributorId
- **位置**：`ruoyi-system/.../api/service/ApiOrderServiceImpl.java:placeOrder()`
- **症状**：前端传 `distributorId` 但 `Order` 对象 `distributorId=null` → `settleForOrder` 找不到 distributor → 0 commission 写入
- **修复**：placeOrder 内 `if (distributorId != null) order.setDistributorId(distributorId);`
- **触发**：C3 smoke 第一次跑就 fail，追到这一行

### 1.2 fixture commission_rule rate 数量级错
- **位置**：`sql/smoke-e13-e17-fixture.sql` (rule 999201/999202) + DB
- **症状**：`rate=0.10` 被代码当作"百分点"，`amount = payAmount × 0.10 / 100 = 0.128 ≈ 0.13`，期望 12.80
- **修复**：`UPDATE biz_commission_rule SET rate=10.00 WHERE rule_id IN (999201, 999202);` + fixture 文件 `0.10 → 10.00`
- **注意**：rule 1 (admin 创建) `rate=10.00` 才是 10% 正确数值

## §2 数值比较陷阱
MySQL DECIMAL 输出 `12.80`，python `print(round(...))` 输出 `12.8`。bash 字符串比较失败。修法：
```bash
num_eq() { python3 -c "import sys; sys.exit(0 if abs($1 - $2) < 0.01 else 1)"; }
```
