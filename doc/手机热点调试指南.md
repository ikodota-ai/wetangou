# 手机热点环境下的真机调试

## 现状

你的环境：电脑连 iPhone/Android 手机热点（不是 WiFi 局域网）。
后端在电脑 `127.0.0.1:8080`，本机 IP `172.20.10.2`。
**手机扫码默认通过 LAN 访问电脑 → 热点下大概率访问不到。**

## 三种解决方案（按推荐度）

### 方案 A：微信开发者工具的"真机调试"（推荐，0 成本）

1. 微信开发者工具 → 顶部菜单 "真机调试" → "微信扫码" 或 "USB"
2. 工具自动建立 IDE → 手机的代理通道，**手机不需要能直连电脑 IP**
3. 后端仍跑在电脑 127.0.0.1:8080，IDE 帮你转发
4. 缺点：依赖 IDE 进程在跑

**操作**：
```
1) 启动微信开发者工具 → 打开 miniprogram7
2) 工具栏右上角 → "真机调试" → 选 "自动真机调试" 或 "扫描二维码"
3) 用同一 appid 绑定的微信扫码
4) Console 输出在 IDE 的调试窗口
```

### 方案 B：让电脑做 WiFi 热点（推荐，需要 WiFi 5GHz 网卡）

1. macOS → 系统设置 → 共享 → "互联网共享"
2. 共享来源：iPhone USB / 蓝牙
3. 共享给：WiFi
4. 手机连这个 WiFi → 走 192.168.x.x → 访问电脑的 192.168.x.x:8080

**操作**：
```
1) macOS 系统设置 → 通用 → 共享
2) 点 "互联网共享"，右侧勾选 "WiFi"
3) "WiFi 选项" 设为 5GHz，密码 12345678
4) 手机 WiFi 连上，电脑 IP 变成 192.168.x.1
5) 改 config.js BASE_URL = 'http://192.168.x.1:8080'
```

### 方案 C：内网穿透（ngrok / frp，跨网络）

- ngrok：账号注册 → `ngrok http 8080` → 拿到公网 URL
- config.js 改成 `https://xxx.ngrok.io`
- 缺点：免费版限速 + 域名会变

### 方案 D：USB 真机调试（最稳）

1. USB 连手机到电脑
2. 微信开发者工具 → "真机调试" → "USB 调试"
3. 走 USB 通道，不依赖网络

## 自检你的环境

```bash
# 1. 看本机所有 IP
ifconfig | grep "inet " | grep -v 127.0.0.1

# 2. 看电脑能 ping 通手机吗
ping -c 2 192.168.1.1  # 通常手机热点下电脑的 gateway

# 3. 看手机能不能反向连电脑（电脑用 nc 监听）
nc -l 8888
# 手机用浏览器访问 http://172.20.10.2:8888
# 如果连不通 = 热点 AP 隔离，需要走方案 A/B/D
```

## 不需要真机也能验证的事（用 curl + 开发工具模拟器）

| 类型 | 工具 | 能验什么 |
|---|---|---|
| 接口 | `curl http://127.0.0.1:8080/api/...` | 后端业务逻辑 |
| 模拟器 | 微信开发者工具 "编译" 模式 | UI、wxml 渲染、JS 执行 |
| 模拟器 | "模拟位置" 在 IDE 顶栏 | 距离计算、最近门店 |
| 真机扫码 | 必须连电脑网络 | 支付、定位、扫码核销 |

**最实用建议**：
- 90% 问题在 IDE 模拟器就能定位
- 真机只测**网络**（支付回调、扫码核销）相关
