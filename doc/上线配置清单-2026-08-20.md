## 1. 环境变量（必填）

放 `/etc/dytuangou/dytuangou.env`，systemd 用 `EnvironmentFile=` 引入。

```bash
# ---- 数据库（application-prod.yml 已参数化）----
export DB_HOST=rm-xxx.mysql.rds.aliyuncs.com
export DB_PORT=3306
export DB_NAME=dytuangou
export DB_USER=dytuangou            # 不要用 root
export DB_PASSWORD='强密码'
export DB_USE_SSL=true

# ---- JWT 签名密钥（application.yml 已参数化）----
# 仓库默认值是 abcdefghijklmnopqrstuvwxyz，等于公开密钥，必须换
export JWT_SECRET="$(openssl rand -base64 48 | tr -d '\n')"

# ---- Druid 监控页（application-prod.yml 已参数化，默认关闭）----
export DRUID_STAT_ENABLED=false      # 需要排查时才临时 true
export DRUID_STAT_USER=druid_admin
export DRUID_STAT_PASSWORD='强密码'

# ---- 阿里云 OSS ----
export OSS_ENDPOINT=https://oss-cn-hangzhou.aliyuncs.com
export OSS_REGION=cn-hangzhou
export OSS_BUCKET=wetangou-prod
export OSS_ACCESS_KEY=LTAIxxxx
export OSS_SECRET_KEY=xxxx
export OSS_CDN_DOMAIN=https://cdn.你的域名.com

# ---- Redis ----
export REDIS_HOST=r-xxx.redis.rds.aliyuncs.com
export REDIS_PORT=6379
export REDIS_PASSWORD='强密码'
```

验证：`systemctl show dytuangou -p Environment` 或启动日志里 druid 连的是 RDS 地址。

## 2. 微信 / 支付凭证（sys_config，必填）

当前库里 `wx.open.*` 7 项 + `wx.pay.*` 6 项**全是空串**，
`wx.pay.notifyUrl` 还是占位 `https://your-domain.com/api/pay/notify`。

```bash
# 1) 改占位符
vim sql/deploy/sys_config_production.sql

# 2) 备份后执行
mysqldump -h$DB_HOST -u$DB_USER -p $DB_NAME sys_config > /tmp/sys_config_backup.sql
mysql --default-character-set=utf8mb4 -h$DB_HOST -u$DB_USER -p $DB_NAME < sql/deploy/sys_config_production.sql

# 3) 关 mock（双保险：代码层已强制，DB 也改掉避免误判）
mysql -h$DB_HOST -u$DB_USER -p $DB_NAME -e "
UPDATE sys_config SET config_value='false'
 WHERE config_key IN ('wx.miniapp.mockEnabled','wx.pay.mockEnabled');
UPDATE biz_merchant SET mock_enabled='1';   -- 注意：本字段 0=开mock 1=关mock（语义反的）
"

# 4) 清 Redis 缓存（sys_config 有缓存）
redis-cli -h $REDIS_HOST -a $REDIS_PASSWORD FLUSHDB
```

必填清单：

| key | 说明 |
|---|---|
| `wx.miniapp.appId` / `wx.miniapp.secret` | 平台自有小程序 |
| `wx.pay.appId` / `mchId` / `apiV3Key` / `certSerialNo` / `privateKeyPath` | 微信支付 v3 |
| `wx.pay.notifyUrl` | **必须是公网 HTTPS**，指向 `/api/pay/notify` |
| `wx.open.componentAppId` / `componentSecret` / `componentToken` / `componentAesKey` / `templateId` / `redirectDomain` / `apiBaseUrl` | 多商户代发布（不做代发布可留空） |

## 3. 小程序端 BASE_URL（必改）

`miniprogram7/utils/config.js` 现在默认指向局域网 `http://172.31.26.216:8080`，
`BASE_URL_FALLBACKS` 也全是内网地址。上线前二选一：

- **方案 A（单商户，推荐）**：把 `resolveBaseUrlDefault()` 的返回值和 fallback 列表改成
  `https://api.你的域名.com`，重新上传小程序。
- **方案 B（多商户代发布）**：保持代码不动，靠 `ext.json` 注入 `baseUrl`
  （`MpReleaseServiceImpl.buildExtJson` 会写 `sys_config['wx.open.apiBaseUrl']`）。
  这条路要求 `wx.open.apiBaseUrl` 必须配好。

小程序后台还要配：request / uploadFile / downloadFile 合法域名（都填 HTTPS 域名），且域名需已备案。
