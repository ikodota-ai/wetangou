## §1 端到端验证

### 1.1 后端 getInfo 返回 userType
```bash
TOKEN=$(curl -X POST -H "Content-Type: application/json" \
  -d '{"username":"agent001","password":"admin123"}' \
  http://localhost:8080/login | jq -r .token)
curl -H "Authorization: Bearer $TOKEN" http://localhost:8080/getInfo | jq '{userType, agentId, merchantId}'
# → {"userType":"1","agentId":1,"merchantId":null}
```

### 1.2 菜单按 userType 过滤（agent vs platform）
- **agent001** (userType=1)：getRouters 返 6 个 agent 菜单（agent/agentfee/merchant/merchantfee/mprelease/mpauth）
- **admin** (userType=0)：getRouters 返完整平台菜单（含 system/* / monitor/* / tool/* / biz/* 全套）

→ 实际等价于按 userType 过滤：platform 看到全平台，agent 看到 agent 维度，merchant 看到 merchant 维度。

### 1.3 前端跳转
- `login.vue:resolveEntryPath()` 根据 store.user.userType 决路径
- handleLogin 完成后 `this.$router.push({ path: this.redirect || this.resolveEntryPath() })`
- 路由 `/agent/index` + `/merchant/index` 已在 `ruoyi-ui/src/router/index.js` 注册（hidden:true — 不出现在侧边栏，但可路由访问）
