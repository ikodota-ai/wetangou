# 洞天团购 · 微信小程序 PRD（产品需求文档）

> 文档版本：v1.0（2026-07-31）  
> 基准参考：`doc/prod_img/` 33 张产品截图 + 4 张补充截图  
> 目标实现：`miniprogram7/`（全新 1:1 复刻，替换 `miniprogram6/`）

## 1. 项目背景

基于 RuoYi-Vue 二次开发的多店铺到店团购小程序 C 端。原 `miniprogram6/` 由于早期设计/实现脱节、模块组织混乱，`miniprogram6` 不删除作为参考样本，本 PRD 驱动一个**全新项目 `miniprogram7/`**。

### 1.1 业务目标
- 多店铺到店自取团购闭环。
- 在线预约、到店买单（店员确认 + 代金券）、推客分销与提现。
- 复刻现有产品截图，**1:1 视觉与交互**还原。

### 1.2 名词约定
| 名词 | 含义 |
| --- | --- |
| 门店 | 后台维护的实体店铺，含地址、营业时间、电话、坐标 |
| 商品 | 到店自取团购套餐，含封面、价格、规格、须知、套餐内容 |
| 订单 | 商品购买订单，含核销码、状态、有效期 |
| 预约 | 堂食预约订单，含时段、桌号、手机号 |
| 买单 | 现场消费结算（店员确认金额 + 会员支付） |
| 推客 | 加入分销的会员，享受带货佣金并可提现 |
| 代金券 | 平台/商家发放的抵扣券，在买单/订单中抵扣 |

| 主文字 | `#1A1A1A` | 标题、关键内容 |
| 次文字 | `#666666` | 描述、辅助 |

| 分割线 | `#EEEEEE` / `#F0F0F0` | 列表分割 |
| 警示红 | `#FA5151` | 错误、未通过、取消 |
| 链接蓝 | `#576B95` | 协议链接 |

- **字体**：Noto Sans SC（系统默认 PingFang/Source Han Sans 兜底）
- **圆角**：通用 `12rpx ~ 24rpx`；按钮 `999rpx` 全圆或 `12rpx`
- **阴影**：仅在弹窗使用 `0 0 0.5px rgba(0,0,0,0.05)` 风格，整体偏扁平
- **像素**：Pixso rem → 微信 `rpx`，基准 1rem≈32rpx，按视觉微调

### 2.2 字体规格（rpx）
| 用途 | 字号 | 字重 |
| --- | --- | --- |
| H1（页面大标题） | 36~40 | 700 |
| H2（卡片标题） | 30~32 | 600 |
| 正文 | 26~28 | 400/500 |
| 注释/标签 | 22~24 | 400 |
| 价格主 | 36~40 | 700 |
| 价格辅（删除线） | 22 | 400 |

### 2.3 布局规则
- **页面安全区**：顶部预留状态栏 + 导航栏 88rpx；底部 tabBar 高度 100rpx（自定义）。
- **卡片间距**：页面级 `margin: 20rpx 16rpx`；卡片内边距 `24rpx ~ 32rpx`。
- **左右边距**：16rpx（与系统一栏式视觉一致）。

### 2.4 通用交互
- **Tap 反馈**：使用 `hover-class="opacity"` 或自定义 `active` 态。
- **Toast**：成功/失败统一 `wx.showToast({ icon, duration })`。
- **模态确认**：用 `wx.showModal`，深色场景用自定义 `<modal>`。
- **Loading**：使用 `wx.showLoading` + `hideLoading` 配对，标题"加载中"。
- **空状态**：居中"暂无XX"灰色文字 + 极简图标。
- **错误态**：行内红字 + Toast 提示。

## 4. 功能详述

### 4.1 登录授权
- **入口**：未登录状态下打开小程序任意页面 → 引导到登录页；或"我的-未登录"点击。
- **流程**：
  1. 进入登录页 → 显示小程序头像/昵称授权按钮（`button open-type="chooseAvatar"` + `input type="nickname"`）。
  2. 用户完成授权后 → 调用 `wx.login` 拿 `code` → 调后端 `/api/auth/login` 换 `token`。
  3. 勾选用户协议 + 隐私协议（未勾选时点击"授权登录"提示"请先阅读并勾选协议"，截图 `登录页-提示`）。
  4. 暂不登录：以游客身份进入，可浏览但下单/预约/买单受限。
- **后端字段**：`memberId`, `openid`, `nickName`, `avatarUrl`, `phone`, `token`。
- **失败态**：网络失败 → Toast；token 失效 → 自动退出并回到登录页。

### 4.2 门店首页
- **数据**：基于位置获取最近门店；定位失败取第一门店。
- **结构**（自上而下）：
  1. 顶部品牌色 Header（透明渐变 `linear-gradient(#3A6B35 → #7AAA5A)`）
  2. 轮播（2~3 张门店活动图，indicator-dots）
  3. 门店卡：店名 + 买单按钮（绿色）、评分（暂无评分）、营业时间、可堂食/可预约标签、详情入口
  4. 地址操作条：地址 + 距离、导航、联系商家（圆形 icon 按钮）
  5. 双入口卡：预约到店 / 在线咨询
  6. Tab 选项卡：到店自取 / 预约服务
  7. 商品列表（自取） / 堂食预约入口卡（预约服务）
- **交互**：
  - 轮播最后一张点击 → 切到"贴图"。
  - "详情 >" → 弹出"设施及服务"抽屉（可堂食、可预约、提供独立包间、提供免费停车场、免费停车）。
  - "在线咨询" → 弹底部 modal：客服电话（13434123069） + 工作时间 + 暂未配置二维码。

### 4.3 贴图/相册
- Tab 切换（全部(2)）→ 网格 2 列大图，缩略图圆角 16rpx。

### 4.4 预约（堂食）
- **预约选择页**：展示门店卡 + 单张"堂食预约"图片卡，点击进入时段填写。
- **时段填写页**：
  - 预约项目：堂食预约（仅一项，胶囊式选中态）
  - 预约时间：横向日期 07-25/26/27/.../更多日期 + 白天/晚上切换 + 时段（11:00/12:00/17:00...）
  - 预约人信息：手机号（必填）、备注（≤20 字）
  - 预约说明：店规则（"本店全周年午晚市开放预约...超时自动作废；用餐前 2 小时可免费取消；到店出示预约码核验入座。"）
  - 底部"立即预约"按钮
- **预约成功**：弹窗"您的预约已提交，请等待商家确认" + "我知道了" → 跳我的预约列表。
- **预约详情**：项目/时间/取号时间/手机号/备注/编号 + 取消预约。

### 4.5 商品购买
- **商品详情**：
  - 顶部图 1/1 + 分页指示
  - 价格卡（绿色长条，¥498 现价 + ¥498 删除线原价 + 折扣标签"10.0 折热销中" + 已售 0）
  - 标题 + 须知/服务/门店 三行
  - 套餐详情：项目名 + (N 份) + ¥单价
  - 购买须知：可用/不可用/时间/张数/人数/规则
  - 适用门店 1 家 + 缩略图
  - 本店更多商品 3
  - 底部固定：商家/分享/订单 icon + 立即购买 ¥498
- **授权手机号**：点击"立即购买"→ 校验登录 → 未授权手机号则弹授权弹窗 → 用户点击"授权手机号"触发 `button open-type="getPhoneNumber"` 系统弹窗 → 同意后写入会员手机号 → 跳提交订单；点"暂不授权"关闭弹窗。
- **错误态**：商品已过售卖期 → 弹错误详情弹窗（关闭 / 复制错误码）。
- **分享卡**：分享弹窗含头像、昵语、商品大图、名称、价格、二维码、3 个圆形操作（发送给朋友 / 收藏 / 保存图片）。
- **提交订单**：
  - 门店行：icon + 菌鑫来餐饮 + "1 家店通用 >"
  - 商品行：缩略图 + 名称 + ¥498.00 + ¥498.00
  - 购买份数：步进器 1（− 数字 +）
  - 到店自取：选中态（淡绿底 + 右上角 ✓ 徽章）
  - 姓名/手机号：会员已认证自动填，否则手动输入
  - 商品总价 + 需付款（绿色）
  - 底部：合计 ¥498.00 + 提交订单（绿色按钮）

### 4.6 订单
- **列表**：5 个 Tab 切换（全部/待支付/待使用/已完成/退款售后），右上"..."菜单支持客服等快捷操作。
- **空态**：居中"暂无订单"灰色文字。
- **详情**（不在截图列表，按需求可有可无，PRD 中标"待定"）。

### 4.7 买单

### 4.8 我的（个人中心）
- 头部渐变 + "Hi," + 名字/点击注册/登录 > + 头像
- 订单四宫格：全部订单 / 待支付 / 待使用 / 退款/售后
- 功能列表（统一行高 100rpx，右箭头）：
  - 推客中心（带绿色钱袋 icon）
  - 会员资料（带头像 icon）
  - 我的预约（带日历 icon）
  - 用户协议（带文档 icon）
  - 隐私协议（带盾牌 icon）
  - 联系客服（带头戴耳机 icon）

### 4.9 会员资料

### 4.10 推客中心

### 4.11 商家地址/客服

## 6. 接口约定（来自 RuoYi-Vue 后端 `/api/**`）

> 本次只做前端 1:1 复刻，接口字段以 `miniprogram6/utils/request.js` 为基线。详见 §10 错误与降级。

| 模块 | 方法 | 路径 | 用途 |
| --- | --- | --- | --- |
| 认证 | POST | `/api/auth/login` | code → token |
| 会员 | GET | `/api/member/profile` | 拉取昵称/头像/手机号 |
| 会员 | PUT | `/api/member` | 更新资料 |
| 会员 | POST | `/api/member/phone` | 绑定手机号 |
| 会员 | upload | `/api/member/avatar` | 头像上传 |
| 门店 | GET | `/api/store/list` | 门店列表 |
| 门店 | GET | `/api/store/{id}` | 详情 |
| 门店 | GET | `/api/store/{id}/album` | 门店相册 |
| 商品 | GET | `/api/product/list?storeId=` | 商品列表 |
| 商品 | GET | `/api/product/{id}` | 商品详情 |
| 订单 | POST | `/api/order` | 创建订单 |
| 订单 | POST | `/api/order/prepay/{id}` | 预支付 |

## 7. 数据 Mock 与降级

- **门店 / 商品**：若接口失败，使用 `utils/mock.js` 内置店铺、商品、订单样例，确保所有页面可独立预览。
- **位置**：未授权位置时取 mock 坐标。
- **登录**：未拿到 `code` / 后端未启动 → 启用 mock token，本地写入 `globalData.user`。

## 10. 错误与降级策略

| 场景 | 处理 |
| --- | --- |
| 网络失败 | Toast"网络异常，请稍后重试"，按钮恢复可点 |
| 401 token 失效 | 清除 token + 跳转登录页 |
| 位置未授权 | 默认第一门店 + Toast 提示 |
| 商品不存在/已下架 | 详情页弹"商品已过售卖期"错误弹窗 |
| 未授权手机号 | 弹"授权手机号"弹窗（不阻塞其他浏览） |
| 后端 mock 关闭 | 全部走内置 mock 数据 |
