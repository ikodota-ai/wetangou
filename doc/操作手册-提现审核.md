# 提现审核操作手册

## 流程
1. 推客小程序 → 我的 → 提现申请（金额+账户）
2. 后台管理员 → 提现管理 → 待审核列表
3. 管理员点击"通过"或"驳回"（驳回必须填原因）
4. 推客端 → 提现记录 → 看到 status 更新

## 关键端点
- 推客申请：`POST /api/distributor/withdraw`
- 推客列表：`GET /api/distributor/withdraw/list`
- 后台列表：`GET /biz/withdraw/list`（admin token）
- 后台审核：`POST /biz/withdraw/audit {withdrawId, status:1/2, failReason?}`

## 业务规则
- status=0 待审核
- status=1 通过 → distributor.withdrawAmount += amount；availableAmount 不变（申请时已扣）
- status=2 驳回 → distributor.availableAmount += amount（退回可提现余额），failReason 必填

## 实测验证（2026-08-04）
- 100002 通过 → withdrawAmount 0→10.00 ✅
- 100003 驳回 → availableAmount 7.80→12.80 ✅
